# 使用本地插件

插件可以添加论文库菜单、PDF 选区操作和命令，也能订阅阅读事件、保存设置及私有数据。目前支持桌面应用中的本地 Vault。

## 安装与启用

打开 **设置 → 插件 → 从文件夹安装…**，选择包含 `manifest.json` 和 `main.js` 的插件目录。

![插件管理页](../assets/plugins-settings.png)

安装后默认停用。打开插件开关，选择授予当前 Vault 的权限，调整设置，再点击 **保存并启用**。插件行的配置按钮可再次修改权限与设置。

![插件权限与设置](../assets/plugins-permissions.png)

| 权限 | 可执行的操作 |
|---|---|
| 读取 Vault 文件与论文 | 读取论文信息、笔记、文本及已有解析结果 |
| 修改论文标签和已读状态 | 更新标签、标记已读或未读 |
| 写入论文笔记 | 追加或替换论文笔记正文 |
| 写入 Vault 文本及移动论文 | 修改普通文本、移动论文目录 |

只启用信任的代码。授权按 Vault 保存，切换到其他 Vault 后需要另行启用。设置与插件私有数据保存在本机，不随 Vault 同步。

## 试用阅读工具

源码仓库提供 `examples/plugins/reading-tools` 示例，安装后可验证：

1. 在论文库中右键一篇论文，选择 **标记论文为已读**。
2. 在 PDF 中选中文字，选择 **将选区保存到笔记**。选区会追加到该论文的 NOTES，并采用设置中的「笔记标题」。
3. 打开命令面板，搜索 **查看阅读次数**，读取插件记录的论文打开次数。

命令面板快捷键为 macOS `⌘⇧P`、Windows/Linux `Ctrl+Shift+P`。插件只能调用已授权的操作；缺少权限时会显示失败提示。

## 停用、更新与卸载

- **停用**：关闭开关，立即移除命令和菜单，并取消在途执行。
- **更新**：重新安装同 ID 的目录。新源码替换已安装快照，所有 Vault 的旧授权与设置重置，需要重新启用。
- **卸载**：点击垃圾桶按钮，删除插件包和授权；保留本机私有数据，方便重装后继续使用。

修改原始插件目录不会自动改变已经安装的代码。在线市场、自动更新和签名发布不在当前版本范围内。

开发插件请参阅 [本地插件系统与 API](../backend/plugins.md) 及仓库中的 `examples/plugins/sdk.d.ts`。
